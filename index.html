Политика конфиденциальности приложения «Trading Journal»

Дата последнего обновления: 1 ноября 2026 г.

1. Общие положения

Настоящая Политика конфиденциальности описывает, какие данные собирает, хранит и обрабатывает мобильное приложение «Trading Journal» (далее — Приложение).

Используя Приложение, вы соглашаетесь с условиями настоящей Политики.

2. Какие данные мы собираем

Приложение не собирает персональные данные.

  • Все записи о сделках, настройки, история чата и голосовые данные хранятся только на вашем устройстве.
  • Приложение не передаёт ваши данные на серверы, не требует регистрации и не использует аккаунты.

3. Передача данных третьим лицам

Приложение использует интернет только для запросов к публичным API для получения справочной информации:

  • курсы криптовалют: CoinGecko;
  • курсы валют: open.er-api.com, Twelve Data;
  • акции и индексы: Yahoo Finance, MOEX;
  • новости: Bing News, TASS, Лента.ру, РБК;
  • поиск информации: Wikipedia, DuckDuckGo.

Эти запросы не содержат ваших персональных данных и не позволяют идентифицировать вас.

4. Голосовой ввод

Голосовой ввод (GigaAM) работает полностью офлайн. Аудио не покидает ваше устройство и не передаётся на серверы.

5. Хранение и удаление данных

Вы можете удалить все данные в любой момент через раздел «Очистка» в Приложении. Также данные удаляются при удалении Приложения с устройства.

6. Дети

Приложение не предназначено для лиц младше 18 лет.

7. Изменения в Политике

Мы можем обновлять настоящую Политику. Актуальная версия всегда доступна на этой странице.
